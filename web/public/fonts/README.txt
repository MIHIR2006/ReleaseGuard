Optional: MetaMask's hero typeface

The headline font in this project is "Grotzec Cond" (Grotzec Cond Bold), a commercial typeface from Feliciano Type.
It is NOT included here because it needs a licence.

If you have a licensed copy, either
  1) install it on your computer (the page uses it automatically), or
  2) copy the web font into this folder with one of these exact names:
       GrotzecCond-Bold.woff2
       GrotzecCond-Bold.otf

Without it the page uses Bebas Neue, a free font with a very similar look.
